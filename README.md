# landing-page# Landing Page

## Introduction

This project is part of [The Odin Project](https://www.theodinproject.com/) Foundations course. The goal is to recreate a landing page using HTML and CSS based on a provided design.

By completing this project, I will demonstrate my ability to structure a webpage using HTML, style it with CSS, use Flexbox to arrange and align elements, and control spacing, typography, colors, and layout to match a reference design.

This project will also help me practice organizing CSS rules and turning a visual design into a functional webpage.
